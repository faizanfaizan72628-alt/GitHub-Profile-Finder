
# 🔎 GitHub Profile Finder
A beginner-friendly and responsive web application that allows users to search for GitHub profiles and view public information using the GitHub REST API.
## 🚀 Features
- 🔍 Search GitHub users by username
- 🖼️ Display profile pictures
- 👤 Show name, username, and bio
- 📦 Display public repositories
- 👥 Show followers and following
- 📍 Display location when available
- 🔗 Visit the user's GitHub profile
- ⚠️ Handle invalid usernames and API errors
- 📱 Responsive design for mobile and desktop
## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub REST API

## 💻 How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter a GitHub username in the search box.
5. Click the Search button to view the profile.
## 🌐 API Used
GitHub REST API:
https://api.github.com/users/USERNAME
Replace `USERNAME` with the GitHub username you want to search for.
